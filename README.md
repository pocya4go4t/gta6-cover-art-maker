Sunset Cover Studio — a GTA-style cover art maker that runs fully offline in a desktop browser. Load any photo (or a built-in sample), drop it into a multi-panel poster layout, drag to crop and scroll to zoom, pick a sunset, neon, gold or noir colour grade, write a bold caption, and export a 1080×1080, 1080×1350 or 1920×1080 PNG. All lettering uses the Anton and Oswald fonts shipped under app/fonts/ (SIL Open Font License); the sample photos are original images made for this app and free to use.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
